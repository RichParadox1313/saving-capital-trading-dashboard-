How to Build a Proper Quant Analysis
01
Identify the Regime
Start by understanding the current market state — trending, ranging, or transitioning. This determines which other tools are relevant.
HMM Regimes Kalman Filter
02
Assess Volatility
Before sizing any position, understand the current vol regime and forecast. This drives stop placement and position sizing.
GARCH Model
03
Find the Trend & Target
With regime and vol confirmed, identify trend direction, entry zone, and price target using regression or time-series models.
Regression Channel ARIMA Neural Network
04
Validate Risk Parameters
Before executing, simulate your strategy parameters to ensure the risk of ruin and drawdown profile are acceptable.
Monte Carlo
Tool When to Use Key Inputs What It Tells You Combine With
Monte Carlo Before going live with a new strategy. Use to stress-test parameters before real capital. Win rate, R:R ratio, risk per trade, number of trades Probability of ruin, expected drawdown, realistic P&L range across scenarios GARCH for vol-adjusted sizing
GARCH Model Anytime before sizing a position or setting a stop loss. Always check vol first. Asset symbol, model type (GARCH/EGARCH), forecast horizon Current conditional volatility, persistence of shocks, vol regime (low/moderate/high) HMM for regime context · Monte Carlo for sizing
Regression Channel Trending markets only. Use R² to confirm a trend exists before applying. Asset, band width (σ), forecast horizon Trend direction and strength, overbought/oversold vs the channel, price target GARCH to set band width · Neural Net for directional confirmation
Neural Network Use as a directional signal confirmation — never as the sole reason to trade. Architecture (LSTM/GRU), sequence length, forecast horizon, features Predicted direction, confidence level, MAE/RMSE accuracy metrics Regression for structural levels · HMM for regime validity
ARIMA Model Short-horizon forecasting on liquid, stationary assets. Best for mean-reverting markets. p, d, q parameters, forecast horizon Point forecast with confidence interval, model fit (AIC/BIC), forecast reliability Neural Net for non-linear patterns · Kalman to pre-smooth
HMM Regimes First step of any analysis. Determines which other tools are applicable. Asset (select from live prices), number of states (2–4) Current market regime, stability score, regime probability distribution Use output to decide: Bull → trend tools · Bear → mean-reversion · Neutral → wait
Kalman Filter Noisy markets and high-frequency data. Pre-process before other models. Q (process noise), R (measurement noise), model type Clean trend signal, signal-to-noise ratio, market trending vs choppy classification Regression on filtered signal · ARIMA on residuals
Recommended Tool Combinations
Trend Trade Setup
HMM → GARCH → Regression → Monte Carlo
Confirm bull regime, check vol is moderate (not extreme), find channel entry, validate risk parameters before sizing.
Mean Reversion Setup
HMM → Kalman → ARIMA → Monte Carlo
Confirm neutral/ranging regime, extract clean signal, forecast the reversion target, stress-test position sizing.
Volatility Breakout Setup
GARCH → HMM → Neural Net → Regression
Identify vol compression, confirm regime transition forming, get directional signal, find breakout target in channel.
Strategy Validation
Monte Carlo → GARCH → HMM
Run simulations with realistic win rate and R:R, adjust position size for current vol, check if regime supports the strategy.

Confidence Score
How strong is the current quant signal? (0–100)
What is the Score?
The Confidence Score is a deterministic calculation — not an AI estimate. It sums 5 price-action factors, each worth up to 20 points, into a single 0–100 reading computed fresh from live market data every time. The written analysis alongside it adds further context (institutional positioning, funding rates, sentiment, macro regime) but does not change this number.
Signal Levels
80–100STRONG BUY — All factors aligned bullish, high conviction
65–79BUY — Majority of factors confirm upside bias
50–64NEUTRAL — Mixed signals, no clear directional edge
35–49SELL — Majority of factors confirm downside bias
0–34STRONG SELL — All factors aligned bearish, high conviction
The 5 Analysis Factors (0–20 each)
Momentum
Scores the size of the 24-hour price move — bigger moves in either direction score higher, reflecting stronger directional velocity right now.
Trend
Checks whether the 24-hour move and the 5-day move point the same direction. Confirmed trends score higher than moves that contradict the recent trajectory.
Volatility
Rewards a healthy, tradeable volatility range. Both dead-quiet and extreme/chaotic volatility score lower than a moderate, trending range.
Relative Strength
Compares this asset's 24-hour move against the average of its peers in the same market category — outperforming the peer group scores higher.
5-Day Momentum
Same idea as Momentum but over a 5-day window, to weigh in the medium-term trajectory alongside the 24-hour reading.
Live Data Sources
📋
CFTC COT Report
Weekly Commitment of Traders data from the US Commodity Futures Trading Commission. Shows net long/short positioning of hedge funds, commercials, and retail across Gold, Oil, EUR/USD, GBP/USD, and Bitcoin futures.
💸
Perpetual Funding Rates
Real-time funding rates from Binance futures for BTC, ETH, SOL, XRP. Positive = longs are crowded and paying shorts (squeeze risk up). Negative = shorts crowded (squeeze risk down).
😨
Crypto Fear & Greed Index
Composite sentiment index 0–100. Below 25 = extreme fear (historically a buy zone). Above 75 = extreme greed (historically a sell zone). Used as a contrarian signal in the mean reversion factor.
🔗
Cross-Asset Correlations
Live Pearson correlation computed from rolling price history across key pairs: Gold/DXY, Gold/BTC, BTC/ETH, DXY/EUR. Correlation breakdowns signal regime shifts before they appear in price alone.
